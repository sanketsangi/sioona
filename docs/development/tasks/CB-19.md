## Infrastructure and deployment contract

`render.yaml` declares site, web, API, worker and ingestion recovery separately.
The marketing site remains independently deployable. Web services have HTTP
liveness checks; workers/crons have no Render HTTP health-check facility.
Long-running services have 120-second shutdown budgets. Uvicorn has a 110-second
grace period; worker SIGTERM stops claims and drains via its existing lease fence.
Shutdown timeout is bounded: lease expiry/replay handles a process killed after
that deadline; it is not a guarantee that arbitrary provider calls finish.

All Python consumers run `scripts.check_schema` before starting. It only reads
`alembic_version` and compares the exact code head; it never runs migrations.
Secrets and tenant allowlists are supplied out of band (`sync: false`), worker
claims start paused, LLM dispatch starts disabled, and application auto-deploy is
off. Applying the blueprint is a separate approved operator action and may incur
spend; this card does not apply it. Existing dashboard service adoption requires
an operator diff first. The recovery cron needs its approved owner/recovery URL;
API/worker require the restricted runtime URL.

or predeploy hooks. The API `/health` remains liveness, not database readiness;
canonical routes fail closed when the database becomes unavailable.

## Repeating the local drills

```sh
cd backend
.venv/bin/python scripts/rehearse_launch_drills.py --report /tmp/cb19-drills.json
.venv/bin/python scripts/rehearse_launch_drills.py --all-postgres --report /tmp/cb19-postgres.json
```

The runner creates and destroys its own loopback-only PG17 cluster in a temporary
directory. It accepts a binary directory, never an external database URL; child
environment discards inherited database and provider credentials. Test-owned
schema resets and connection outages only affect `sioona_migration_test`. Each
case has a measured elapsed duration in the JSON report. A failure/skip is not a
successful drill. Dumps and synthetic source rows are deleted with the cluster.

- Worker: pauses after the first persisted publication during an active lease;
  proves drain, no claims while paused, resume, exactly two publications and no
  replay after completion using runtime-role sessions.
- Provider controls: independently commits global and tenant `InferenceControl`
  pauses; requires processing within 60 seconds, zero provider dispatch and
  attempts, heuristic publication and `ai_paused` provenance. No real provider
  endpoint is contacted.
- Database: disables new connections and terminates existing connections to the
  test DB, asserts HTTP `database_unavailable`, restores connections and asserts
  successful canonical reads. Web canonical-store tests independently prove
  fail-closed behavior with stale local state; this is not browser/hosted proof.
- Restore: creates an actual pre-deletion `pg_dump`, completes deletion, keeps a
  trusted receipt outside the restored DB, restores with `pg_restore`, verifies
  old evidence reappeared, reconciles the tombstone before traffic, advances in
  bounded one-row batches with reopened sessions, checks every deletion table,
  zero displayable evidence and the other tenant's surviving conversation.
  Audit, legal holds, counts-only tombstones and financial summaries are retained
  intentionally under CB-18 policy. No promise of instant deletion from backups.
