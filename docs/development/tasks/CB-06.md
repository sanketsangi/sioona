## Scope

Persist one row per billable provider attempt. Web buffers CB-05 `InferenceAttempt`
events, preflights the ledger before the LLM pass (D2), and flushes in `finally`.
Cost rates start empty so cost stays `unknown` until a human enters official pricing.

## Preserved invariants

- No prompt, transcript, or quote text in the ledger table or API payloads.
- Unknown usage and unknown cost are explicit — never zero-filled.
- `SIOONA_ACTOR_AUTH` stays `off` in production; this card does not change actor mode.
- Migration is additive (`021_inference_attempts` after `020_workspaces_memberships`).
- Hosted Alembic / Neon migrate is not run from this agent session.

## Implementation

- Backend: migration 021, model, schemas, `inference_ledger` / `inference_rates`,
  routes (preflight, batch POST, usage GET, detection-run inference GET), wipe count,
  actor route guards, tenant-isolation bodies.
- Web: `ai/ledger.ts`, `ai/run-with-ledger.ts`, `backend-client` batch helpers,
  `computeDetectionRunId`, production detect/ingest/store/hydrate/live-ingest/showcase
  paths use the wrapper. Injectable `classify` and partner-export eval stay unmetered.
- Demo tenant may run without FastAPI (showcase warm). Partner tenants skip LLM when
  preflight fails and record `llmFailure: "ledger"`.

## Known gap (D2)

Buffered attempts are lost if the process crashes before flush. CB-11 closes this by
writing `pending` before the provider call. Flush failures increment
`ledgerFlushFailureCount()` for CB-15 alerting and log counts only.
