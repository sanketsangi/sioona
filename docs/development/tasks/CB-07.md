## Enforcement

Every production detection attempt obtains asynchronous backend admission immediately before fetch, including retries and fallback models. Admission requires a verified actor or narrowly scoped principal even when actor rollout is off/shadow. Preflight failure means heuristics only for every tenant. Tenant inference defaults off until an admin sets positive daily and run attempt limits. The admin-only global control endpoint additionally requires `SIOONA_GLOBAL_CONTROL_TENANT` to designate its authority; principals cannot configure controls. No controls cache is used (0 seconds, below the 30-second maximum). Sanket owns the switch; the propagation contract is no new authorization after the pause transaction commits, within the approved 60 seconds. Already dispatched calls may finish.

Migration 023 creates global/tenant controls, IST daily counters, per-run counters and individual reservations; its global row exists before callers. Admission locks global then tenant controls, consumes both allowances, and inserts a pending inference ledger row with the same attempt ID in one transaction. Tenant limits serialize concurrent independent connections. Retries/fallback each reserve a new attempt. Duplicate admission is denied, settlement is idempotent, and authorized allowances never expire or refund on ambiguity/crash. There is deliberately no reclaim endpoint; a reservation may remain conservative when dispatch cannot be proven. Unknown usage/cost stays unknown.

USD estimation uses official rate lookup, conservative UTF-8 input byte upper bound and an approved output ceiling readiness check. USD admission remains unavailable: official rates and an eval-validated output ceiling have not been approved. Attempt mode is the only configurable enforcement mode. Detection failures remain resumable and show an accessible `role=status` / polite “AI paused” message; no automatic customer sending was added.

## Schema-first operator rollout and rollback

1. A human operator verifies the isolated target and backup, then upgrades to `023_inference_budgets` before deploying callers. Agents must not migrate or seed hosted databases.
2. Configure the designated global-control authority and staging-only actor keys. Keep provider calls disabled while testing. No tenant is implicitly enabled by migration.
3. Deploy the separately CI-verified revision, verify verified-admin controls and scoped principals, and explicitly configure positive tenant limits only when inference is authorized.
4. Exercise pause, backend outage, exhaustion, resumability and concurrent admission. Record operator, UTC times and counts only. Observe the 60-second bound; do not claim a hosted timing test from local tests.
5. Roll back by pausing controls and disabling provider calls before reverting callers. Retain migration 023 and accounting history. Do not deploy old unguarded callers with inference enabled. A schema downgrade deletes history and needs separate human review.
