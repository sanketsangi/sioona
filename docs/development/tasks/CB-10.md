## 2. State Mode Definition (Step 2)

- Flag: `SIOONA_STATE_MODE=postgres|json-demo`.
- Default: `postgres` when in production (`SIOONA_ENV=production` or `VERCEL_ENV=production`), `json-demo` in local development/demo.
- In production (`SIOONA_ENV=production` or `VERCEL_ENV=production`), `SIOONA_STATE_MODE=json-demo` fails closed at boot / request start with an explicit descriptive error (`ProductionRefusesJsonDemoError`).
- In `postgres` mode, non-demo tenants never write or rely on local JSON files for persistent operational state.
